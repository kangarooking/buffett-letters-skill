# Buffett Letters Skill

すぐに使える AI スキルパック——ウォーレン・バフェットの60年以上の株主への手紙から、20個の個別起動・組み合わせ可能な投資判断モジュールに蒸留しました。

これは本の要約ページではありません。本はこれらのスキルの源泉であり、主役ではありません。

## このスキル群が解決する問題

- 株価が急騰していて、追うべきか逃げるべきかわからない
- 企業の真の品質を判断したい（PER や成長率だけでなく）
- 自分が「能力の圏」内で意思決定しているか確信がない
- 「真の保守性」と「保守的に見えるだけのもの」を区別したい
- 勘と断片的な情報ではなく、構造化された投資判断フレームワークが必要

## 何が蒸留されたか

バフェットの株主への手紙（1957-2023）から20個の三重検証済みスキルを抽出し、5つの次元をカバーしています：

- **投資哲学の基礎**：`circle-of-competence`（能力の圏）、`mr-market`（ミスター・マーケット）、`business-picker`（ビジネスを選ぶ、株ではない）、`real-conservatism`（真の保守性）
- **評価と価格付け**：`aesop-three-questions`（イソップの三つの問い）、`margin-of-safety`（安全余白）、`look-through-earnings`（透過利益）、`three-asset-categories`（3つの資産分類）
- **企業品質**：`economic-moat`（経済的堀）、`cigar-butt-vs-great-business`（シガーバット vs 偉大な企業）、`float-thinking`（フロート思考）
- **行動と心理**：`fear-and-greed`（恐怖と貪欲の逆転）、`institutional-imperative`（組織的衝動）、`hold-forever`（永久保有論理）
- **資本配分とリスク管理**：`first-law-of-capital-allocation`（資本配分の第一法則）、`compounding-thinking`（複利思考）、`no-leverage`（レバレッジ拒否）、`never-issue-shares`（増発しない）、`ceo-as-risk-officer`（CEO はリスク責任者）、`partner-with-admired`（尊敬する人と共に）

抽出プロセスは40個の重複除去済み候補から開始し、合格率は約50%でした。

## 効果例

### 例1：急騰する株に直面して

**ユーザーの質問**

「ある株が3ヶ月で80%上がりました。みんなが話題にしています。今すぐ乗るべきですか？」

**スキルの判断**

- まず `mr-market` を起動——これはミスター・マーケットの提示価格か、それとも企業の真の価値変化か？
- 次に `fear-and-greed` を起動——FOMOに駆られていないか確認
- 同時に `circle-of-competence` を呼び出し——この企業を本当に理解しているか？
- 最後に `margin-of-safety` で——現在の価格にまだ安全余白があるか？

**回答例**

> 3ヶ月で80%上昇——まず一つの質問をしてください：この3ヶ月でこの企業のファンダメンタルズに何か変化がありましたか？答えが「あまりない」なら、その80%はミスター・マーケットの提示価格であって、企業価値の成長ではありません。ミスター・マーケットは毎日価格を提示しますが、真実を伝えるためではなく、あなたに彼の感情を利用する機会を与えるためです。次に自分に問いかけてください：見逃す恐怖から動いているのか、それともこの企業を本当に理解しているのか？どうやって稼いでいるのか説明できなければ、能力の圏内ではなく、カジノにいます。最後に価格を見てください：算出できる価値をはるかに超えているなら、安全余白は消滅しており、これは投資の判断ではなく投機の判断です。

### 例2：レバレッジを使うべきか

**ユーザーの質問**

「自分の判断に自信があります。リターンを増幅するためにレバレッジを使うべきですか？」

**スキルの判断**

- `no-leverage` を起動——バフェットのレバレッジに対する一貫した立場と理由
- `margin-of-safety` で補強——安全余白とレバレッジは論理的に矛盾するか？
- 保険/フロートのシナリオが関係する場合は `float-thinking` で——「他人がお金を使わせてくれる」のと「賭けを増幅するために借金する」のを区別

**回答例**

> バフェットの数十年にわたる立場は明確です：レバレッジを使わないこと。理由はレバレッジがリターンを増幅できないからではなく、時間の選択肢を奪うからです。強制清算で一つの正しい判断が吹き飛ばされれば、正しかったこと自体が無意味になります。安全余白の核心は間違いのための余裕を残すこと、レバレッジの論理は間違いを増幅すること——この2つは根本的に矛盾しています。判断に本当に自信があるなら、複利がレバレッジなしでも十分なリターンをもたらします。自信を証明するためにレバレッジが必要なら、その自信自体を見直すべきです。

## これらのスキルはどのように生成されたか

これらのスキルは **cangjie-skill** の RIA-TV++ パイプラインを使用して生成されました。6段階のプロセスです：

1. **全書理解（Adler分析）** — モーティマー・アドラーの分析的読書法で、全書を構造・解釈・批判・応用の4ステップで分解し、`BOOK_OVERVIEW.md` を生成
2. **並行抽出** — 5つの専門エクストラクター（フレームワーク、原則、事例、反例、用語）が同時に実行され、原文から候補ユニットを抽出
3. **三重検証** — 各候補は3つのチェックを通過する必要があります：書中に少なくとも2つの独立した裏付けがあるか（クロスドメイン）、書中に明示されていない新しい質問に答えられるか（予測力）、常識ではないか（独自性）。合格率は通常25〜50%
4. **RIA++ 構築** — 検証済みの内容を6つの次元に構造化：R（原文引用）/ I（自分の言葉での再構築）/ A1（書中の事例）/ A2（将来のトリガーシーン）/ E（実行可能ステップ）/ B（境界と盲点）
5. **ツェッテルカステン連携** — スキル間の依存、対比、構成関係を特定し、参照グラフ付きの `INDEX.md` を生成
6. **ストレステスト** — 各スキルに囮問題を含むテストプロンプトを設計。不合格は段階4に戻って全面的に再構築

各 `SKILL.md` はこのプロセスの実際の出力です。`candidates/` と `rejected/` ディレクトリは完全な監査証跡として保持されています。

## 使い方

1. `INDEX.md` を参照してスキル全体図と依存関係を把握する
2. 現在の問題に関連する `*/SKILL.md` を見つけ、トリガー条件と実行ステップを使用する
3. エージェントフレームワークに統合するか、プロンプトを単独ツールとして使用する
